ZENO VIDEO V1

Fichiers : index.html, watch.html, videos.js, library.js, watch.js, style.css.

Test : ouvre index.html avec un navigateur. Clique sur Regarder.

Pour ajouter une vidéo : téléverse-la dans Cloudinary, puis ajoute un objet dans videos.js :
{id:"PUBLIC_ID",title:"Titre",description:"Description",cloudName:"wnonuvx4"}

Cette version est un prototype. Elle ne comporte pas encore d'interface d'administration ni de téléversement intégré. Ne mets jamais une clé API secrète dans les fichiers publics.
