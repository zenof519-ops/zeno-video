Paramètres d’hébergement — DeepStorage

Zeno Video utilise la clé serveur DEEPSTORAGE_API_KEY pour vérifier l’accès au compte. Elle doit rester dans les secrets Supabase et ne doit jamais être placée dans le code public.

En attente de la première mesure DeepStorage.

La connexion à l’API permet de lire les informations de compte et les droits retournés par DeepStorage. Le quota global de stockage et le trafic ne seront affichés que si l’API les fournit ; les tailles des fichiers Zeno sont mesurées séparément à partir de leurs liens publics.

Mes annonces

Ajouter une vidéo

La vidéo reprendra la couverture de l'annonce et restera en attente jusqu'à ton clic sur « Publier ».

Le mode 480p réduit la résolution avant l'envoi et conserve le fichier original sur ton téléphone. Le traitement peut prendre du temps et utiliser les ressources du téléphone.

Aperçu de la couverture

La miniature sera envoyée sur Cloudinary, quel que soit l’hébergeur de la vidéo. Tu peux choisir ImageKit dans le menu pour utiliser son CDN à la place.

Ouvrir Vioo pour héberger une vidéo ↗

Téléverse d’abord la vidéo dans ton compte Vioo, puis colle ici son identifiant ou le lien de son lecteur. Zeno Video intégrera automatiquement le lecteur.

Ouvrir Dropbox pour héberger une vidéo ↗

Téléverse la vidéo dans Dropbox, crée un lien de partage en lecture seule, puis colle ce lien ici. Zeno Video le convertira automatiquement pour son lecteur vidéo. Le fichier reste hébergé chez Dropbox.

Ce deuxième lien doit être le lien de partage normal (pas le lien embed). Zeno Video l’utilisera avec l’option de téléchargement de OneDrive.

Ouvrir OneDrive pour héberger une vidéo ↗

Ce lien doit être converti en véritable lien d’intégration avant l’enregistrement.

Téléverse ta vidéo sur OneDrive, copie son lien de partage puis reviens ici. Si le lien n’est pas déjà un lien d’intégration, utilise le bouton pour le transmettre à ChatGPT. Le fichier reste hébergé chez Microsoft OneDrive.

Vérification de l'accès API DeepStorage…

Zeno vérifie automatiquement l'accès API. Si l'accès Pro n'est pas actif, cet hébergeur sera refusé et tu pourras en choisir un autre. Les vidéos déjà hébergées sur DeepStorage ne seront pas touchées.

Mux utilisera un envoi direct et sécurisé. Une vidéo indépendante sera publiée automatiquement après traitement. Si elle est liée à une annonce, elle restera « À VENIR » jusqu'à ton clic sur « Publier ».

Le fichier part directement de ton téléphone vers Mux. Zeno Video ne le stocke pas sur GitHub ni dans Supabase. Les vidéos en cours de traitement restent invisibles au public.

Le lecteur adaptatif et le téléchargement sont deux liens distincts. Colle ici l’URL MP4 directe fournie par Bunny (MP4 Fallback), si elle est disponible. Sans ce lien, le bouton Télécharger restera masqué. Aucun mot de passe ni clé API n’est demandé.

Pour cette vidéo déjà envoyée, vérifie dans sa fiche Bunny si des URL MP4 sont affichées. Bunny doit avoir généré le MP4 Fallback avant l’envoi ; sinon, vérifie si le fichier original est conservé.
